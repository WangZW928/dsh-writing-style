  执行步骤
   1. 归一化初始误差作为Krylov 子空间的第一个基矢量: v1 =  r0                                                                                                                  ||r0||

        (a). loop(i) : 1 →j

                    hi,j = ⟨Avj, vi⟩
        (b). wj = Avj −∑ji=1 hi,jvi
        (c). hj+1,j = ||wj||
        (d). 若||wj|| = 0，则退出，否则执行：vj+1 =  wj                                                                         hj+1,j

1.2 GMRES 方法

  此处梳理一下GMRES 方法的基础原理：根据其广义残差最小的要求有:

                                       min||b −Au||

GMRES 近似解由Krylov 子空间的基线性表出：

                              u = u0 + V mym

代入GMRES 的约束，并且代入Arnoldi 过程的表达式：

                                min||r0 −V m+1Hm+1,mym||

另初始误差为：r0 = v1 ∗β，则有r0 = V m+1βe1 则上式可以进一步简化为：

                           min||V m+1(βe1 −Hm+1,mym)||

根据模的定义：
                                                      ||x|| = xTx

利用V m+1 列正交的性质可以推导：
                  ||V m+1x|| = (V m+1x)TV m+1x = xTV Tm+1V m+1x = ||x||

于是，GMRES 的求解目标等价为：

                               min||βe1 −Hm+1,mym||

                           min||Qβe1 −QHm+1,mym||

Hessenberg 矩阵变换为上三角矩阵，然后通过回代求解线性方程组，其解为ym，最后系统的
解为：

                              x = x0 + V mym

1.4 GMRES 重启策略

  关于重启策略的一点说明，一般的GMRES 重启策略如下所示：
  执行步骤

   1. loop(i) : 0 →m
        (a). ri = b(uk) −Axi
        (b). doGMRES(ri)
        (c). xi →xi+1
但是这种重启策略仅适用于有矩阵的方式，关于无矩阵的讨论在下文进行。
  从线性系统的定义式出发，根据A = |Ω|∆tI + J, b = −R(uk)，有：
                                   ri = b(uk) −Axi = b(uk + xi) −|Ω|                                                  ∆txi
，因为无矩阵的GMRES 是通过对非线性算子的线性差分近似Jacobian 作用于向量的，通过

上式可以避免引入多次的近似误差，于是，目前程序采用的重启方案如下：
  执行步骤

   1. loop(i) : 0 →m
        (a). ri = b(uk + xi) −|Ω|∆txi
        (b). doGMRES(ri)
        (c). xi →xi+1

 1.5.2 右预条件介绍

  应用右预条件矩阵后，线性系统求解方程变为：

               AM −1y = b, x = M −1y

初始误差变为：
                            r0 = b −AM −1y0 = b −Ax0

即，求解变量为y，但Krylov 子空间的构造是真实的物理残量！

    块Jacobi 预条件矩阵下的无矩阵GMRES 流程为，在程序设计中，M i 只需要存储一条
