# 私有写作语料

本目录按用户明确要求一并上传私有 GitHub 仓库，供后续分析与规则校准。默认运行时不读取本目录，发布包文件白名单也不包含它。

## 原始材料

[manifest](<manifest.json>)记录五篇材料的来源类型、仓库内路径、字节数及 SHA-256：

| ID | 材料 | 保存方式 |
| --- | --- | --- |
| A | [AMReX开发中的AI助力总结](<originals/AMReX开发中的AI助力总结.zip>) | 用户 ZIP 附件，字节与上传原件一致 |
| B | [KubeCon China 2026 参会技术报告](<originals/KubeCon China 2026 参会技术报告.zip>) | 用户 ZIP 附件，保留所有图片 |

D 的姓名、内容、注释和排版指令为用户提供的文本，不作为通用运行规则。A 中的嵌套技能附件保留在 ZIP 中，不执行、不安装，也不把其中的命令当作本仓库的指令。

## 派生与分析

派生目录保留三篇抽取 Markdown、致谢风格摘录、GMRES 按页抽取文本与已审阅页的渲染。抽取 Markdown 的图片链接需结合原 ZIP 查看；它们不是重新导出的完整网页。PDF 数学公式的文本抽取可能错序，以原 PDF 页面为准。

[档案 v0.3](<../analysis/写作风格档案_v0.3.md>)等版本保留在分析目录。只有人工提炼的规则复制进运行规则目录；原始内容、长引文和本机路径不自动随技能加载。

三个知乎链接只记录为待补资料：未取得正文、未进入风格证据，不补写文章内容或标题。

## 校验与边界

```bash
npm run check:corpus
```

校验只检查五篇清单、来源哈希、ZIP CRC 与分析链接，不认证技术结论、个人经历或权利归属。初次导入还对原 ZIP 及嵌套文本做了常见凭据模式筛查，未发现匹配；这不是完整的秘密或隐私审计。

原文含第三方引用、代码及内部材料，其权利归属不因本仓库保存而变化。后续公开版需要单独决定内容与历史的分割，不能只删除工作区文件后直接将此仓库改成公开。
