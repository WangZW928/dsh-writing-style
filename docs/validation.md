# 首版验证记录

_版本 0.1.0 · 风格档案 0.3 · 2026-11-05_

## 自动化验证

```bash
npm ci --ignore-scripts
npm run check
npm run check:corpus
node bin/cli.js doctor
npm pack
```

本地 Node 24.16.0、DSH 技能 API 0.2.1-rc.5；CI 配置 Node 22。测试使用真实 Cordis Context 与 DSH SkillRegistry，不用自制注册表替身。

12 项 Node 测试覆盖：

1. 私有包、DSH bundle 与运行资源声明。
2. 四种任务、五种文体、十个唯一技能及 metadata。
3. 全部 24 种任务／文体选择组合，含 general 只用共同基础。
4. 未知任务／文体明确报错。
5. curated 文件白名单、路径穿越与任意文件读取拦截。
6. 取消信号停止读取与组合。
7. 真正注册、正文加载、用户同名覆盖和插件卸载。
8. 修订事实约束、数值状态边界、复核与待确认反馈规则。
9. CLI 在陌生 cwd 运行，重复与非法参数报错。
10. 删除语料目录后的运行能力，以及规则符号链接越界拦截。
11. 安装包包含所需运行文件，排除语料、分析、凭据与本地依赖。
12. 规则读取和组合没有独立 fetch 调用，不暴露原始材料路径或个人姓名。

语料校验覆盖五篇来源记录及 SHA-256、ZIP CRC、未读博客状态、分析文档内部链接及已知行号。它不输出原文，不执行语料内命令。

## 安装验收

首版另以打包后的 `.tgz` 在独立临时目录安装，检查 doctor、单分支组合、十个技能在真实注册表中发现与加载，以及卸载后清空。该验收不修改当前使用的 DSH profile，也不默认启用写作风格。

## 结果含义

以上验证的是插件接口、规则编排与资料边界，不是自然语言输出质量评分。没有声称通过静态测试证明模型一定保持公式或事实，也没有进行真实多模型、跨平台 GUI 或长文风格盲评。

实际起草、润色和复核仍由宿主模型执行，需作者试用并确认；反馈功能只产生草案，没有自动规则更新或模型训练。数学／算法正确性、个人经历核实和性能实测均不属于这些测试的结论。
