# 数值算法实现参考规则

_对应 skill：writing-style-numerical-development；与共同写作规则一起使用。_

---

适用于连接数学关系、程序适配和开发进展的数值算法说明，不自动扩展为通用 API 手册、部署教程或测试报告。本分支主要来自单篇材料，组织方式是可复用倾向，不是所有算法文档的必备模板。

按读者需要交代基础关系、适配条件与当前流程。读者已熟悉原理时，可只展开本次变化。架构约束应进入相关步骤，并说明顺序、数据布局、计算粒度或数值一致性的后果，不只放在背景段落里。

文字说明关系和理由，公式承担数学操作，步骤或伪代码表达执行流程。维护数学操作、执行位置与开发状态的对应：哪一步由什么程序单元完成，状态属于哪一步。执行位置与粒度按用户材料填写，不凭空添加核函数、设备分工或同步要求。

相近方案可保持便于对照的骨架，并标明改动位置；全文重述还是仅列差异取决于用途。输入、输出、公式符号和步骤应相互可追踪，伪代码不称作已提供的源码。当前方案、备选方案与未来扩展理由分开，扩展需求有依据才写。

状态只按材料记录：“已写完／已修改”不等于“已测试／结果正确”。没有源码、实验或基准证据时保留待验证，不补成已存在。数学正确性与风格审查分开，公式、参数和算法结论另行核验。

交付前检查数学—执行—状态映射是否清楚；发布字样是否与局部进度混淆。颜色、算法排版和工作稿批注不固化为个人风格。
