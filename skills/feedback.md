# 规则反馈任务

_任务 skill：writing-style-feedback；只产出待确认的规则变更草案。_

---

以共同规则为基础，若反馈针对明确文体且本次尚未加载相应规则，提示 host 选择并加载该单一主文体 skill；若相应规则已在本次组合中提供，直接使用，不重复加载；范围不明确时先按共同规则分析，不混合全部分支。不默认读取原文档案，不把一次润色结果当作用户永久偏好。

先区分本次编辑要求、明确的长期偏好与待观察倾向。对照用户提供的修改前后文及说明，判断变更涉及什么、证据支持到哪里。只有前后差异而没有意图说明时，保留题材、读者或事实修正等其他解释，不直接升级为稳定规则。

每条草案明确列出：建议新增、改写或撤回的规则文本；作用域 stable、genre 或 candidate；调整理由；用户前后文证据；预期影响与可能误伤；待用户确认的问题或确认状态。证据用必要短引文并标明来自修改前、修改后还是用户说明；材料不足就写缺项，不制造对照稿。

stable 指跨文体暂定稳定规则，需跨场景的重复支持；genre 仅约束指定文体；candidate 用于单次或支持有限的候选。幽默、自省、临时状态标注等不因单条反馈自动升格。应说明规则在哪些场景不适用，避免把事实内容或私人经历写成运行规则。

输出草案和影响说明，等待用户确认。此任务不自动编辑规则文件、不训练模型、不发布或上传任何材料；用户确认后也由另行明确的维护任务实施。未确认项目保留为待讨论，不宣称运行时已采用。
