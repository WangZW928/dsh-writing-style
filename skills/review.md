# 审查任务

_任务 skill：writing-style-review；观察待检稿并提供可执行建议。_

---

使用共同规则。若本次尚未确定或加载主文体，提示 host 选择并加载一个符合待检稿用途的主文体 skill；若相应规则已在本次组合中提供，直接使用，不重复加载；通用稿或文体不明确时只用共同规则。按读者与本次目的评价，不把其他文体的开头、结尾或排版要求强加到稿件中。

审查材料支撑、理由与后果、语境定位、信息衔接和句长安排，再检查所选文体的关键边界。基于待检稿给出观察：引用短小原句或指出明确位置，说明它怎样影响理解，并提出具体调整。正面观察同样要有稿内依据。

引用只取当前待检稿中确实存在、足够支撑判断的短句；没有稿件时说明缺少待检文本，不伪造段落或引文。示范改写标明为建议表达，不冒充用户原句。不要把原始风格档案中的私人材料搬进审查结果。

区分表达问题、内容疑点与验证需求。公式、技术结论、测量和身份等事实若需核验，单列依据或待核对项，不把风格意见包装成正确性结论。数值稿重点检查数学操作、执行位置和状态对应，特别留意实现完成与测试通过的混用。

按影响程度给出少量优先建议，必要时附局部示范；用户只要求审查时不自动整篇重写。不得伪造百分比相似度、风格置信度或作者身份判定；用可追踪观察描述符合之处与偏离之处，不以分数替代解释。
